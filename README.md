# flashreserve
FlashReserve adalah aplikasi reservasi stok flash sale berkonkurensi tinggi berbasis TypeScript, Express, PostgreSQL, dan Drizzle ORM. Proyek ini mendemonstrasikan atomic stock decrement, transaksi yang mencegah overselling, reservasi dengan masa berlaku 15 menit, pemulihan stok saat pembayaran demo gagal atau reservasi kedaluwarsa
